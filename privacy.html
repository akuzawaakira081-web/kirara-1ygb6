プライバシーポリシー

制定日・最終更新日：2026年10月31日

KIRARA MUSE（きららMuse）運営（以下「きららMuse」）は、Webサイト「KIRARA MUSE」（以下「本サイト」）と、ChatGPT 向け Plugin「きららMuse ひらめき画像メーカー」（以下「本Plugin」）における情報の取り扱いを、以下のとおり定めます。

1. 本Pluginについて

本Pluginは、ChatGPT の中で動作する指示（Skill）と参考資料だけでできています。本Pluginを動かすためのサーバーやプログラムを、きららMuseは持っていません。

  • きららMuseが OpenAI API を直接利用することはありません。
  • ChatGPT での会話内容や画像を、きららMuse独自のサーバーへ送信しません。
  • ChatGPT での会話内容や画像を、きららMuse独自のデータベースへ保存しません。
  • 本Plugin独自のユーザーアカウントは作成しません。
  • MCPサーバーや外部のAI APIは利用しません。

このため、きららMuseは、本Pluginを使った会話・アップロードされた画像・生成された画像を受け取らず、閲覧もしません。

これらは ChatGPT（OpenAI）のサービスの中で処理・保存されます。取り扱いには OpenAI の利用規約とプライバシーポリシーが適用されます。詳しくは OpenAI のプライバシーポリシーをご確認ください。会話履歴の削除などの管理も、ChatGPT の設定から行えます。

お子さまの写真など、個人を特定できる画像を ChatGPT にアップロードする場合は、保護者の方が必要性を判断したうえでご利用ください。

2. 本サイトについて

  • Cookie・アクセス解析・広告：Cookie、独自のアクセス解析、広告タグは使用していません。
  • ブラウザ内の保存（localStorage）：お気に入りの作品・画像、色見本のお気に入り、技法ページの表示設定、ひらめきレンズの設定（透明度など）を、ご利用のブラウザ内にだけ保存します。この情報はきららMuseへ送信されません。
  • カメラ（ひらめきレンズ）：カメラ映像はブラウザ内で画面に表示するためだけに使います。録画はせず、きららMuseへの送信・保存もしません。カメラを使うには、ブラウザでの許可が必要です。
  • 配信事業者のアクセスログ：本サイトは GitHub Pages と Vercel で配信しています。これらの配信事業者は、配信と安全確保のために、技術的なアクセスログ（IPアドレス、閲覧日時、ブラウザの種類など）を保持することがあります。その取り扱いは各事業者のプライバシーポリシーに従います。きららMuseはこれらのログを個人の特定に使いません。
  • 外部リンク：ChatGPT など外部サービスへのリンクを掲載しています。リンク先での情報の取り扱いは、各サービスの規約に従います。

4. 対象年齢

本Pluginは13歳以上の方が対象です。

  • 13〜18歳の方は、保護者または管理者の同意のもとで利用してください。
  • 13歳未満のお子さまの作品支援に使う場合は、保護者・教員・指導者など成人の方が操作してください。
